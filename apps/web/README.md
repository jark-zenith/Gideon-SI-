# GIDEON SI Presence Interface

Status: FOUNDATION / PARTIALLY IMPLEMENTED.

This is the first visual presence foundation, not the completed GIDEON application.

Current capabilities:
- GIDEON SI interface shell.
- Holographic presentation treatment.
- Existing approved repository character reference displayed as the visual source.
- Idle, listening and thinking presence states.
- Browser-native push-to-talk speech recognition when supported.
- Explicit messaging when GIDEON Core is not connected.

Not yet implemented:
- Real LLM connection.
- Authentication.
- Supabase persistence.
- Text-to-speech.
- Realtime voice.
- 3D character rendering.
- Facial animation or lip sync.
- GitHub repository inspector.
- Memory.
- Autonomous agents.

No simulated AI result is presented as a real result.

The asset at assets/gideon-reference.png is an alias of the existing approved repository image. The original root asset remains preserved.
